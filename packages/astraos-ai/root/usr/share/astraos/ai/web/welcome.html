Welcome to AstraOS

An independent desktop distribution built on Debian 13 packages, with an assistant that runs on this machine and a help centre that needs no network. This is an alpha release: read the last section before you put it on the machine you work on.

Ask the assistant

Type astra ai in a terminal, or start it from the menu. It runs locally, needs no account, and it does what it is asked - with a confirmation for anything that changes the machine.

Find an answer

Open the help centre - every how-do-I page, searchable, on this machine, with no connection needed.

See the machine

The dashboard (astraos-hud) shows the CPU, memory, network, disks and temperature. astraos-doctor prints a health report you can paste into a bug report.

The first ten minutes

  1. Update the system. sudo apt update && sudo apt upgrade. This asks for your password; the assistant never does that for you, on purpose.
  2. Know that the firewall is on. It blocks everything inbound except the assistant's page on your private network. ufw status verbose shows the rules.
  3. Install what you need. sudo apt install <name>, or the Software entry in the menu, which is the same thing with a window on it.
  4. Set up one backup before you install anything large. The help centre's backup page has the commands.
  5. Pair your phone if you have one: astra ai start --lan prints a code, and the phone becomes the assistant's microphone and keyboard.

What is not proven yet

  • No install has been run on physical hardware. The image is proven in CI, on emulated machines.
  • The image is not signed. It boots under Secure Boot because it carries Debian's signed chain, not because AstraOS signs anything.
  • The APT archive is unsigned and, for now, has to be added by hand.
  • No browser-based web applications have been launched inside a booted image in CI; the network stack itself is proven.

The complete list, with the reasoning and the run records behind it, is in docs/KNOWN_LIMITATIONS.md.
